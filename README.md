# Projet wifi intelligent 

An intelligent Wi-Fi project in a startup model environment that will use multiple protocols and measurement emulation to calculate and determine the optimized locations for each device during their routine.

## Features :

* A simulation of devices and routines + daynight cycle
* A database to include the sign in informations of each device
* Multi-program intercommunication API
* AI models trained to predict bad service and traffic times.

## Requirements :

* Ubuntu (Preferably LTS) with a valid `mac80211_hwsim ` module.
* Python 3.8+

## Installation :

1. Open your terminal and type ; `git clone https://github.com/flimple/wifi-intelligent-mininet`
2. Then use `./install_deps.sh` inside your installed folder to check the installation of requirements and dependencies.
